# I'm *go*ing to learn [Go Lang](https://go.dev/)

**Date:** 11-5-2026

---

### What sparked the interest in Go?

I recently installed Chimera Linux, and it doesn't have Big G in it. This means I can't compile the Rust programs I write without installing libgcc, and I generally don't like [glibc](https://en.wikipedia.org/wiki/Glibc), [GCC](https://en.wikipedia.org/wiki/GNU_Compiler_Collection), or libgcc.

This motivated me to find another suitable and popular programming language to use, and Go seems to be a good pick.

I won't know if Go is right for me until I actually learn it, so I'll be creating a monorepo for my Go code.
